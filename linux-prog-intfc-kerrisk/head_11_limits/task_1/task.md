# Задание
Попробуйте запустить программу из листинга 11.1 в других реализациях UNIX, если у вас есть такая возможность.

## Понятия
`sysconf()` - позволяет приложению получить значения системных ограничений в ходе выполнения программы
```
#include <unistd.h>

long sysconf(int name);
```
где:
- `name`: является одной из констант вида _SC_*

возврат:
- возвращает значение ограничения, указанного в аргументе name, при успешном завершении или –1, если ограничение не определено или же если произошла ошибка.
