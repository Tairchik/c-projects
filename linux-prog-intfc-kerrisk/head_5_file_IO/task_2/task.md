# Задание

Напишите программу, открывающую существующий файл для записи с флагом 
O_APPEND, а затем переведите файловое смещение в начало файла перед записью каких
либо данных. Куда в файле будут помещены добавляемые данные? Почему?

## Понятия
> *O_APPEND* - это **флаг состояния файла**, записи добавляются исключительно в конец файла.</br>
> *lseek* - **изменение файлового смещения**.  Оно обозначает место в файле, откуда будет стартовать работа следующего системного вызова read() или write(). 

## Результат программы
```
Hello!!! Hi!!! 
```
Сначала была записана строка "Hello!!!" и, после смещения указателя (lseek), записана строка "Hi!!!"


## Вывод
<h4>Куда в файле будут помещены добавляемые данные?</h4>
<p>Согласно флагу O_APPEND, т.е. в конец</p>
<h4>Почему?</h4>
<p>Флаг O_APPEND делает <strong>записи</strong> атомарными на уровне ядра ОС.<br>
При вызове write ОС выполняет:<br>
1) Перемещает указатель текущей позиции (lseek) в <strong>конец файла</strong>.<br>
2) Записывает данные.</p>
Также подмечу, что при чтении из файла (read) указатель <strong>не сбрасывается</strong> в конец.
