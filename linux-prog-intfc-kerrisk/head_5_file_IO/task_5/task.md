# Задание
Напишите программу для проверки совместного использования файловыми дескрипторами значения файлового смещения и флагов состояния открытого файла.

## Понятия
`fcntl()` - выполняет операции управления файлом, используя дескриптор открытого файла.

```
#include <fcntl.h>

int fcntl(int fd, int op, ... /* arg */ );
```
где:
- `fd`: файловый дескриптор;
- `op`: операции;
- `arg`: опциональный 3-ий аргумент, обязательность определяется в зависимости от опций.
 
Операции, которые будут использованы:
- `F_GETFL(void)`- возвращает флаги состояния файлового дескриптора.
- `F_SETFL(int)`- установить флаги состояния (затирает старые). 

`dup()` - на основании аргумента _oldfd_ открывает файловый дескриптор, возвращая новый дескриптор, ссылающийся на ту же самую дескрипцию открытого файла.

```
 #include <unistd.h>

 int dup(int oldfd);
```

`lseek` - **изменение файлового смещения**.  Оно обозначает место в файле, откуда будет стартовать работа следующего системного вызова `read()` или `write()`. 
```
off_t lseek(int fd, off_t offset, int whence);
```
где:
- `fd`: файловый дескриптор;
- `offset`: смещение;
- `whence`: директива, указывающая относительно чего смещение:
    - _SEEK_SET_: относительно начала файла;
    - _SEEK_CUR_: относительно текущего смещения;
    - _SEEK_END_: относительно конца файла.

## Результат программы
```
Новое смещение: 4
Старое смещение: 4
Смещения одинаковы.

Маска до изменения флагов: 32770
Маска флагов состояния нового дескриптора: 33794
Маска флагов состояния старого дескриптора: 33794
Маски одинаковы.
```

## Вывод
При совместном использовании открытых файлов, как **одним** процессом, так и **несколькими** у них становятся общими флаги состояния и файловое смещение.

Для проверки над разными процессами можно использовать команду `fork()`. Результат будет таким же.
