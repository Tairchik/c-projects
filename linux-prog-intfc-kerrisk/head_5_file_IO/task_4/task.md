# Задание
Реализуйте функции `dup()` и `dup2()`, используя функцию `fcntl()` и, там где это необходимо, функцию `close()`. (Тот факт, что `dup2()` и `fcntl()` в некоторых случаях возникновения ошибок возвращают различные значения errno, можно проигнорировать.) Для `dup2()` не забудьте учесть особый случай, когда _oldfd_ равен _newfd_. В этом случае нужно проверить допустимость значения _oldfd_, что можно сделать, к примеру, проверкой успешности выполнения вызова `fcntl(oldfd, F_GETFL)`. Если значение _oldfd_ недопустимо, функция должна возвратить –1, а значение errno должно быть установлено в EBADF.

## Понятия
`fcntl()` - выполняет операции управления файлом, используя дескриптор открытого файла.

```
#include <fcntl.h>

int fcntl(int fd, int op, ... /* arg */ );
```
где:
- `fd`: файловый дескриптор;
- `op`: операции;
- `arg`: опциональный 3-ий аргумент, обязательность определяется в зависимости от опций.
 
Операции, которые будут использованы:
- `F_DUPFD(int)` - дублирование файлового дескриптора с наименьшим номером, указанным в _arg_ типа **int**;
- `F_GETFL(void)`- возвращает флаги файлого дискриптора. 

`dup()` - на основании аргумента _oldfd_ открывает файловый дескриптор, возвращая новый дескриптор, ссылающийся на ту же самую дескрипцию открытого файла.

`dup2()` - создает дубликат файлового дескриптора, заданного в аргументе _oldfd_, используя номер дескриптора, предоставленный в аргументе _newfd_. Если файловый дескриптор, указанный в _newfd_, уже открыт, `dup2()` сначала закрывает его.

```
 #include <unistd.h>

 int dup(int oldfd);
 int dup2(int oldfd, int newfd);
```
