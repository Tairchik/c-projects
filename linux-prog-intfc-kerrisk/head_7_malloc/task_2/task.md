# Задание
(Повышенной сложности.) Реализуйте функции malloc() и free().

## Понятия
`malloc()` - выполняет динамическое выделение памяти в куче (heap) заданного размера _size_ байт.
```
#include <stdlib.h>

void *malloc(size_t size);
```
где:
- `size`: число выделяемых байт

возврат:
- Указатель на начало выделенной памяти. В случае ошибки - NULL

`free()` - освобождение памяти по переданному указателю _ptr_, указатель должен быть получен из семейства malloc-ов, иначе при передаче случайного указателя или указателя, не ссылающегося на начало выделенного блока памяти влечет за собой непредсказуемое состояние, но обычно возвращается ошибка Segmentation Fault. Если передать NULL, то функция ничего не сделает.

```
#include <stdlib.h>

void free(void *_Nullable ptr);
```

`brk()` - вызов устанавливает крайнюю точку программы (program break) на место, указанное окончанием сегмента данных - _addr_. Память выделяется по странично, _addr_ округляется до границы следующей страницы. Возвращает в случае успеха 0, ошибки -1.

```
#include <unistd.h>

int brk(void *addr);
```
`sbrk()` - вызов увеличивает крайнюю точку программы на _increment_ байт и возвращает указатель на начало выделенной памяти. Если _increment_ равен 0, возвращает позицию крайней точки программы. В случае ошибки возвращает указатель _(void *) -1_

```
#include <unistd.h>

void *sbrk(intptr_t increment);
```

### Реализация `malloc()` и `free()`
При вызове `malloc()`. Сначала сканируется список ранее высвобожденных функцией `free()` блоков памяти, чтобы найти блок, размер которого больше или равен свободной части. Поиск осуществляется по стратегии _первый подходящий блок_.  Если блок в точности подходит по размеру, он возвращается вызывавшему функцию коду. Если он больше по размеру, то он разбивается, и вызывавшему функцию коду возвращается блок подходящего размера, а свободный блок меньшего размера остается в списке свободных блоков.

Если в списке нет подходящего блока, функция `malloc()` вызывает `sbrk()` для выделения большого количества памяти. Для уменьшения вызова `sbrk()` выделяют несколько страниц.

Для того чтобы функция `free()` понимала, какого размера свободный блок используется следующий подход:
> слева от выделенной памяти указывается размер выделенного блока.


После освобождения блока справа записываются два указателя на следующий и предыдущий свободный блок, тем самым создается список свободных блоков.

Примечание: указатели записываются на место высвободившего блока памяти, поэтому минимальный размер выделяемый памяти равен 8 (2х4) и 16 (2х8) байт для 32 и 64 разрядных системах, соответственно (далее аналогично). И также для удобства реализации длина блока будет соответствовать 4 или 8 кратному размеру выделенной памяти, т.е. при вызове `malloc()` с размером 17 байт выделится 20 или 24 байт, соответственно, а также 4 и 8 байт под поле "длина блока", в итоге получаем 24 и 32 байт, соответственно.

Итоговый минимальный размер вызова `malloc()` составит 12 и 24 байт.

Соединение блоков должно выполняться при высвобождении блока, т.е. вызова `free()`.

Алгоритм:
```
[Вызов free(*ptr)]
> Смотрим на флаги соседей:
>   1) Сосед слева: size = *(ptr - 2)
>      if size % size_of(size_t) == 0 (Пусть 0 говорит о занятости)
>       ...
>      else join(ptr, ptr - *(ptr - 2) + 1)
>
>   2) Сосед справа: size = *(ptr + *(ptr - 1) + 1)
>      if size % size_of(size_t) == 0
>       ...
>      else join(ptr, ptr + *(ptr - 1) + 2)
```
