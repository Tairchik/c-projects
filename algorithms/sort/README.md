# Стенд для тестирования и анализа алгоритмов сортировки

Данный проект представляет собой автоматизированную лабораторную среду на языке Си для тестирования, замера производительности и анализа временной сложности различных алгоритмов сортировки.

---

## 📁 Структура проекта и навигация

Проект организован по модульному принципу. Все исходные коды алгоритмов изолированы в отдельном каталоге, что позволяет легко масштабировать стенд.

```text
.
├── main.c                  # Главный управляющий файл (генерация данных, потоки, замеры)
├── sort.h                  # Общий заголовочный файл с интерфейсами функций сортировки
├── Makefile                # Скрипт автоматической сборки проекта
└── src/                    # Каталог с реализациями алгоритмов
    ├── bubble/             # Сортировка пузырьком
    │   ├── bubble.c
    │   └── task.md         # Анализ и результаты теории/тестов пузырька
    ├── insertion/          # Сортировка вставками
    |    ├── insertion.c
    |    └── task.md        # Анализ и результаты теории/тестов вставок 
   ...
```

## ⚙️ Архитектура: как организована работа (main.c)
Файл main.c выполняет роль центрального диспетчера бенчмарка. Работа организована следующим образом:
- **Входные параметры**: программа принимает из аргументов командной строки размер массива (`./executable [size]`). Если размер не указан, используется значение по умолчанию ($1000$ элементов).

- **Генерация данных**: для исследуемого алгоритма динамически выделяется память (`malloc`) и генерируются три типа массивов (для проверки всех теоретических случаев):
  - **Хороший случай** — массив изначально отсортирован по возрастанию.
  - **Плохой случай** — массив отсортирован в обратном порядке (по убыванию).
  - **Случайный случай** — массив заполнен хаотичными числами с помощью `rand()`.
- **Многопоточное тестирование** (`pthread`): чтобы минимизировать влияние операционной системы на замеры и изолировать вычисления, для каждого типа массива создается отдельный POSIX-поток (`pthread_t`). Сортировки запускаются параллельно в своих `thread_worker`.

- **Высокоточное измерение времени**: замер времени производится внутри потоков с помощью системного таймера `clock_gettime(CLOCK_MONOTONIC)`, что позволяет фиксировать результаты с точностью до наносекунд, исключая процессорное время других системных процессов.

- **Вывод результатов**: после синхронизации потоков (`pthread_join`) программа форматирует и выводит в консоль данные: имя запущенного алгоритма, размер выборки и время работы для каждого случая.

- **Тестирование**: Определен макрос ENABLE_TESTS. При запуске создаются тесты проверяющий правильность сортировки

## 🛠️ Управление проектом с помощью `Makefile`
### Основные команды:
- Сборка всех доступных сортировок:

  ```
  make
  ```
  Или make all. В корне проекта автоматически создадутся исполняемые файлы с именами алгоритмов (например, bubble и insertion).
- Сборка конкретной программы:
  ```
  make bubble
  ```
- Для отладки:
    ```
    make DEBUG=1
    ```
- Для тестирования:
    ```
    make TEST=1
    ```
- Очистка проекта от бинарников и объектных файлов:
    ```
    make clean
    ```
### Как запустить программу:
После успешной сборки запускайте нужный бинарник, передав ему размер массива (например, 100 тысяч элементов):
```
./bubble 100000
./insertion 100000
```

### Как добавить новый алгоритм в стенд:
1. Создайте в `src/` папку с названием алгоритма, например `src/selection/`.

2. Внутри создайте файл с точно таким же названием: `selection.c`.

3. Реализуйте в нем функцию `int sort(int *array, int size);`.

4. Откройте Makefile и просто добавьте имя папки в первую строчку к переменной `SORTS`:
   ```
   SORTS = bubble insertion selection
   ```
